# テニスチーム管理

監督が選手の育成・管理に使う、チーム全員が見られる画面です。ビルドなしの HTML/JS と Supabase(データベース・ログイン・ファイル保存)でできています。
コート検索(リポジトリの他の部分)とは独立しているので、新しいリポジトリへ `team/` ごと移せます。

## できていること(第1弾: 全タブの骨組み)

| タブ | 中身 |
|---|---|
| 選手 | プロフィール(自分で編集。ランク・チームは監督だけ) |
| 試合記録 | 日付・相手・スコア・勝敗・メモ + 画像/ファイル添付 |
| 試合情報 | 出たい大会の日程・場所・URL |
| ニュース | 記事のURLとひとこと(手で登録) |
| 動画 | 参考動画のURL・タグ・ポイント |
| 最安値 | 商品ごとに、見つけた店・価格・確認日を記録 |
| ノート | テニスノート |
| ミーティング | 議事録と決まったこと |
| テスト | 筆記/実技/体力。1行 = 1人の1回分 |
| ランク | チームごとにランク順で一覧 |

権限: ログインした人は全員が全部を見られます。追加は誰でも、編集・削除は本人か監督だけです。

## まだ作っていないこと(次の段階の案)

- 試合結果の画像(スコア表の写真)から、スコアを自動で読み取る
- ニュース・試合情報・最安値の自動取得(取得先ごとに規約を確かめてから)
- 選手ごとの勝率・成績グラフ
- テスト結果の推移、ランクの履歴
- 招待の画面(今は Supabase の管理画面から)

## 設置の手順(最初の1回)

1. https://supabase.com で無料のプロジェクトを作る。
2. SQL Editor に `supabase/schema.sql` を貼って実行する。
3. Authentication → Providers → Email で **「Allow new users to sign up」を OFF** にする(招待した人だけが入れるように)。
4. Authentication → URL Configuration に、公開するページのURLを入れる(ログインのメールのリンク先)。
5. Authentication → Users → Invite user で、自分と選手のメールアドレスを招待する。
6. 自分(監督)を監督にする。SQL Editor で:
   `update profiles set role = 'coach' where id = (select id from auth.users where email = '自分のメール');`
7. `web/config.js` に Project URL と anon キーを入れる(**service_role キーは入れない**)。
8. `web/` を GitHub Pages か Cloudflare Pages で公開する。

## 注意

- データを守っているのは `schema.sql` の行レベル制限(RLS)です。画面の隠しボタンではなく、データベース側で止めます。
- 添付ファイルは非公開の保存場所に置き、見るたびに1時間だけ有効なリンクを作ります。
- 選手の名前・成績・写真が入るので、公開ページのURLが漏れてもログインなしでは何も見えません。ただし未成年の写真を載せる場合は、保護者の同意など運営側のルールを決めてください。
