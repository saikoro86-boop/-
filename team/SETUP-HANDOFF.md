## 守ってほしいこと(重要)
- **秘密を、画面・チャット・ファイル・commit に出さないでください。** 対象は、データベースのパスワード、`service_role` キー、`CODE_PEPPER`、アクセストークンです。

  - `CODE_PEPPER` は、値を画面に出さずに作って、そのまま `supabase secrets set` に渡してください(PowerShell の変数に入れる方法が README にあります)。変えると、発行済みのコードが全部使えなくなります。

- Supabase CLI は、グローバルに入れず、`npx supabase ...` で動かしてください。Docker を求められたら、`supabase functions deploy` に `--use-api` を付ける方法を試してください(この方法が使えるかは、あなたが確かめてください)。
